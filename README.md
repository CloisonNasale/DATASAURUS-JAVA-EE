# 🦕 Datasaurus 🦕
Un système de gestion de base de données sur les dinosaures, très simple, fait avec Java EE ! Vous pouvez voir, ajouter, supprimer et modifier des dinosaures.
<img width="1907" height="916" alt="datasaurus" src="https://github.com/user-attachments/assets/5e15c357-e802-47a9-9aec-a878cd4fc8d9" />

## Installation de la Base de Données
1. Créez une base de données nommée `bdd_sdzee`.

2. Importez le script SQL `db_setup.sql` pour créer les tables et insérer les données de base.
